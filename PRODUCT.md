# Product
<!-- impeccable:product-schema 1 -->

## Platform
desktop

Electron desktop application, targeting macOS first. React is rendered inside isolated desktop windows.

## Stack
User-specified Electron, React, TypeScript; token-based CSS; lightweight SVG mascot.

## Users
University students studying lecture PDFs, notes, websites, and problem sets alongside other applications.

## Product Purpose
One connected learning workspace and desktop companion. The approved glass visual system now serves exactly two modes: topic-free AI tutoring and PDF lecture walkthroughs. Saved material, history and settings directly support them.

## Capabilities and Constraints
Stage 3 was explicitly authorized on 14 November 2026 and is being delivered in committed chunks. Real ElevenLabs conversations and Anthropic visual analysis require user-configured credentials. Local study data persists on this Mac; lecture context, released voice questions and activation-scoped screen snapshots go to the configured providers. Each held question captures only the display under the pointer, including whatever the user has on that display. Never retain screenshots in the local database or continue capture after pause/stop. macOS permissions are requested once; no per-question application consent checkbox. The authored glucose-phosphorylation visual lesson has saved steps and tutor narration. fal generates labelled visual analogies (main-process key, bounded verified downloads, saved locally with lesson step, session and lecture slide); generated images are never presented as precise science. Practice uses six authored questions; option answers are graded deterministically and written answers by Claude against an authored model answer, and a possible misconception is saved only with a quote from the student's own words. Review suggestions come only from each question's latest answer. No arbitrary generated lesson engine, general practice engine, computer control or simulated learning analytics is implemented yet. Preserve the canonical CoderEren/yoteach repository; use a separate branch; never merge without approval.

## Brand Commitments
Name: yoteach. Tagline: A tutor that sees what you see. Mascot: replaceable Yoyo, a twin-disc frosted lavender and icy-blue yo-yo with an expressive string. Premium restrained liquid glass, readable surfaces, system typography, iris accents. Intelligent, approachable and concise tone.

## Accessibility & Inclusion
Keyboard navigation, clear focus, reduced motion, readable contrast, light and dark themes. Explain empty, loading and error states. Never equate time spent with understanding.
